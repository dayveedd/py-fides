What is the "PayPal Rails Oracle"?

In pyFides, the Fiduciary Oracle is the automated verification engine. When Seller Agent Beta delivers digital work (e.g. compute logs, sentiment data), the Oracle verifies that its SHA-256 hash matches the agreed Cart Mandate. Only upon confirmed match does the Oracle fire a REST call to PayPal Rails (POST /v2/payments/authorizations/{id}/capture) to release escrow funds! If the deliverable is tampered or late, it automatically voids the hold to refund the buyer.
